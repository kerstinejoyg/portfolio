# Personal Portfolio

A responsive one-page portfolio website designed and developed to showcase my professional experience, technical skills, services, and selected company projects.

## 🌐 Live Website

[View Live Portfolio](https://kerstinejoyg.github.io/portfolio/)

## 📌 About

This portfolio was designed and developed to present my experience as a Front-End Developer and highlight selected websites and digital projects I contributed to throughout my professional career.

The website focuses on a clean, modern, and responsive user experience across desktop, tablet, and mobile devices.

## ✨ Features

- Responsive one-page layout
- Smooth scrolling navigation
- Active navigation state while scrolling
- Responsive mobile navigation menu
- Interactive project slider using Swiper.js
- Interactive services section
- Responsive project cards
- Custom animations and visual effects
- Contact form with email delivery
- Mobile-friendly design
- Accessible HTML structure
- Organized and maintainable code structure

## 🛠️ Technologies

- HTML5
- CSS3
- SCSS / SASS
- JavaScript
- jQuery
- Swiper.js
- SVG
- Git
- GitHub
- GitHub Pages
- Web3Forms
